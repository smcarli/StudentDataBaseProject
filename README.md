# Student Database Project

## By Siena Carli

A student database management system built using C++ in VS Code

## What it can do:
- Add students
- View all students
- Search for students by ID numbers
- Delete students
- Save student information
- Load student information when the program begins

## How to use the system:
- When the program starts you will be presented with a menu of options from 1-6
- Enter the number corresponding to the action you want to complete
- Continue using the menu to manage the student database
- Select option 6 to exit the program

## Technologies used:
- C++
- Visual Studio Code
- GitHub
- File I/O
